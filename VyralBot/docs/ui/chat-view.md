# Chat View

## Overview
XAML view for the chat interface. Displays messages from multiple platforms with a send message input.

## Source Files
- **XAML:** `src/VyralBot.UI/Views/ChatView.xaml`
- **Code-behind:** `src/VyralBot.UI/Views/ChatView.xaml.cs`
- **DataContext:** `ChatViewModel`

## Features
- Message list with auto-scroll
- Platform selector dropdown
- Per-platform settings popups (Twitch, Kick, YouTube, TikTok)
- Message input with send button
- Badge display via `BadgesToImagesConverter`
